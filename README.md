# Сэмплотека

Библиотека сэмплов для звукорежиссёров под Windows и macOS. Добавляете папку со звуками (хоть 160 ГБ), приложение само читает названия, папки и параметры файлов и раскладывает всё по категориям. Файлы на диске остаются на своих местах: приложение ничего не переименовывает и не перемещает.

## Что умеет

- **Автокатегории на русском и английском.** 20 разделов и около 110 подкатегорий для звуков кино и игр (оружие, магия и фэнтези, транспорт, фоли, атмосферы и т.д.). Учитываются имя файла, папки и коды UCS (`WEAPSwrd_`, `MAGElem_`). Дерево категорий — `src/shared/taxonomy.js`.
- **Самообучение.** Поменяли категорию у звука — приложение запоминает незнакомые слова из названия и переносит похожие звуки. Само находит в библиотеке новые слова и раскладывает звуки без категории по соседям в папке. Можно завести свои категории со своими словами (кнопка «Обучение»).
- **Распознавание по звуку (по желанию).** Нейросеть YAMNet (Google, AudioSet, 521 класс) слушает первые секунды файлов прямо на компьютере, без интернета, и помогает там, где название ничего не говорит. Работает через MediaPipe (WebAssembly), лицензия Apache 2.0.
- **Интерфейс на русском и английском.**
- **Поиск на двух языках.** Запрос «бочка» найдёт и `Kick_Punchy_01.wav`. Можно писать «120 bpm».
- **Фильтры:** ваншоты, лупы, длинные звуки, темп, тональность, длительность.
- **Прослушивание с волной:** стрелки ↑ ↓ переключают звуки и сразу играют их, пробел ставит на паузу, клик по волне перематывает.
- **Перетаскивание в DAW:** тащите строку или кнопку «Тащите в DAW» в Reaper, Ableton, FL, Cubase, Premiere и т.д.
- **Избранное, недавние, ручная смена категории** (хранится только в приложении).
- **Быстрый повторный скан:** неизменённые файлы не перечитываются.

Форматы: WAV (включая 24/32-бит, RF64, темп из ACID-чанка), AIFF, MP3, FLAC, OGG, M4A.

## Установка

Готовые файлы собираются автоматически на GitHub: вкладка **Actions** → последняя успешная сборка «Сборка под Windows» → артефакт **Sampleteka-Windows**. Внутри:

- `Sampleteka-Setup-x.y.z.exe` — обычный установщик;
- `Sampleteka-Portable-x.y.z.exe` — запускается без установки.

Windows может предупредить, что издатель неизвестен (у приложения нет платной подписи): «Подробнее» → «Выполнить в любом случае».

Каждый пользователь хранит свою библиотеку у себя: `%APPDATA%\Sampleteka\library.json`.

### macOS

Сборка «Сборка под macOS» → артефакт **Sampleteka-macOS**:

- `Sampleteka-…-mac-arm64.dmg` — для Mac на Apple Silicon (M1–M4);
- `Sampleteka-…-mac-x64.dmg` — для Mac на Intel.

Откройте .dmg и перетащите «Sampleteka» в «Программы». У приложения нет платной подписи Apple, поэтому при первом запуске macOS его не откроет. Нужно один раз: правый клик по приложению → «Открыть» → «Открыть». На новых версиях macOS (15 и выше): «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть». Если пишет, что приложение «повреждено», в Терминале: `xattr -cr /Applications/Sampleteka.app`.

## Для разработки

```bash
npm install
npm start                      # запустить приложение
npm test                       # тесты категоризации и сканера
npm run demo-library -- ./demo # создать тестовую папку со звуками
node scripts/build-preview.js  # собрать демо-страницу интерфейса в dist/preview.html
```

Правила категорий лежат в `src/shared/categorize.js`: чтобы научить приложение новому слову, добавьте его в список `words` нужной категории и увеличьте `RULES_VERSION`, тогда библиотека пересортируется при следующем запуске.
